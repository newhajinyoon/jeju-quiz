# 🍊 제주어 맞추기! (Jeju Dialect Quiz)

제주어 문장을 보고 표준어 문장으로 번역하여 맞추는 웹 기반 퀴즈 게임입니다.  
사라져가는 아름다운 말, 제주어를 재미있게 배워보세요!

## 📌 프로젝트 소개
이 프로젝트는 사용자가 제주어(방언) 문장을 읽고, 그에 해당하는 표준어 번역을 빈칸 채우기 형식으로 맞추는 퀴즈 애플리케이션입니다.  
단순한 텍스트 입력이 아닌, **직관적인 빈칸 UI**와 **자동 문장 부호 처리**, **단계별 힌트 시스템**을 통해 학습 효과와 재미를 동시에 제공합니다.

## ✨ 주요 기능

### 1. 게임 플레이
- **빈칸 채우기:** 제시된 제주어 문장을 보고 표준어 단어를 입력합니다.
- **자동 문장 부호:** 마침표(.), 쉼표(,), 물음표(?), 느낌표(!) 등의 특수문자는 자동으로 처리되어 단어 입력에만 집중할 수 있습니다.
- **정답 확인:**
    - 맞은 단어는 **초록색**으로 고정됩니다.
    - 하나라도 틀리거나 빈칸이 있으면 오답으로 처리됩니다.

### 2. 힌트 및 난이도 시스템
- **하트(기회) 시스템:** 오답 시 하트가 하나씩 줄어듭니다.
- **자동 초성 힌트:** 틀릴 때마다 **숨겨진 단어 중 하나가 랜덤으로 초성 힌트**로 바뀝니다.
- **난이도 조절:**
    - 🟢 **쉬움:** 기회 9번
    - 🟡 **보통:** 기회 6번 (기본값)
    - 🔴 **어려움:** 기회 3번

### 3. 디자인 및 UI
- **제주 테마:** 제주 감귤색과 현무암색을 활용한 깔끔한 디자인.
- **감성 폰트:** `함초롬바탕` 웹폰트를 적용하여 읽기 편안하고 감성적인 분위기 연출.
- **반응형:** 모바일과 데스크톱 환경 모두 지원.

## 🛠 사용 기술 (Tech Stack)
- **HTML5:** 시맨틱 마크업 구조.
- **CSS3:** Flexbox 레이아웃, CSS 변수(Variables), 반응형 디자인.
- **JavaScript (Vanilla):** 외부 라이브러리 없이 순수 자바스크립트로 로직 구현.
